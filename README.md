## Project Description
Have you ever been overwhelmed in deciding which outfit to wear when you're on a time crunch?
Well fear not for we have created an application that will help generate good outfits for your catered style, input the temperature, budget, and reason for needing a marvelous outfit! 
Personalized outfit generator: you specify the vibe, the temperature, and your budget for the day, and the app assembles outfits using real items, complete with store information and pricing for each piece.
- Project for the CSC207 (Software Design) course, University of Toronto.

## Features
- User registration and login 
- Preferences: vibe, price range, measurements (private), and location 
- Outfit generation based on weather, vibe, and budget
- Inventory browsing (shirts, pants, shoes, jewelry, hair do and make-up suggestions)
- Saving and viewing favorite outfits
- Plan your own outfit on a model before trying it on   

## User Stories

1. As a user, I want to see various outfit options for a specific occasion, tailored to the current temperature.
2. As a user, I want to browse my inventory and select specific items.
3. As a user, I want to save my preferences so that I receive recommendations that match my size and personal vibe.
4. As a user, I want to hand pick my own outfit and see it on someone before I change into it
5. As a user, I want to save time from my day thinking about outfits and be ready to ace the day 

## Architecture

Clean Architecture, with dependencies pointing inward:
- Make different purposes of our code in different classes to keep code organized
- Test cases will be made first to ensure code works as expected
- Code will be reusable, this project can be adapted to code a similar idea without having to change much content
